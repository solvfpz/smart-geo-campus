# Smart Geo Campus - Attendance Tracking

This is a VS Code ready project for the Smart Geo Campus system.

## Features
- Login system (Student/Admin)
- Location-based attendance (Geo-fencing)
- Real-time student tracking
- Attendance history with CSV/PDF export
- Admin dashboard with analytics

## How to Run
1. Open this folder in **Visual Studio Code**.
2. Install the **Live Server extension** in VS Code.
3. Right-click on `index.html` → "Open with Live Server".
4. The project will run in your browser at `http://127.0.0.1:5500` (default).
